# 🚍 Bus Finder – Staff App

The **Bus Finder Staff App** is a mobile application designed for bus staff (drivers, conductors, and supervisors) to efficiently manage daily operations.  
It integrates with the **Admin Portal** and **Passenger App**, ensuring smooth coordination between staff, passengers, and administrators.

---

## 📌 Features (Functional Requirements)

### Staff Capabilities
- 🔑 **Log in and view assigned shifts** – Access daily work schedules and assigned buses.  
- ⏱ **Start and end assigned shifts** – Manage work attendance digitally.  
- 📍 **Share live GPS location** – Automatically transmit the real-time bus location to the system.  
- 🪑 **Update bus capacity / seat availability** – Keep passengers informed about seat availability during trips.  
- 🚨 **Send SOS/emergency alerts** – Instantly notify the admin in case of emergencies.  
- 🚌 **View route and bus details** – Access assigned bus and route information.  
- 🔔 **Receive shift-related notifications** – Get real-time alerts and updates from the admin.

---

## 🛠 Tech Stack
- **Frontend:** Flutter (cross-platform)  
- **Backend Integration:** REST APIs  
- **Authentication:** Secure login with JWT / OAuth  
- **Location Services:** GPS tracking for live updates  
- **Notifications:** Push notifications for shift updates and alerts
